# Source logos

These assets identify job sources in the landing-page hero. They are not partnership or endorsement badges. Keep their original lettering, colours and proportions.

- `seek.svg`: official header SVG from https://au.seek.com/, retrieved 19 October 2026. Removed page-specific CSS class names; paths and colours are unchanged.
- `indeed.svg`: official header SVG from https://www.indeed.jobs/, retrieved 19 October 2026. Removed page-specific testing and accessibility attributes; paths and colours are unchanged. Brand guidance: https://indeed.design/brand/logo/.
- `apsjobs.svg`: official white header logo from https://content.apsjobs.gov.au/themes/custom/custom/apsjobs/logo__header.svg, retrieved 19 October 2026. Kept unmodified and displayed on a dark background.

The employer career-sites category uses a generic building icon because it represents many separate employers.
